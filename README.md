# 太行 SOLO · 会员与积分超市

短剧平台的会员套餐、积分超市与支付弹窗交互原型，使用单文件 HTML、CSS 和 JavaScript 实现。

[查看当前展示页面](https://taihang-pricing-membership.cy894590383.chatgpt.site/membership/#plans)

## 使用方式

下载或克隆仓库后，直接用现代浏览器打开 `index.html`，无需安装依赖或构建。

- `index.html#plans`：创作会员套餐
- `index.html#shop`：积分超市

页面字体通过 Google Fonts 加载；无法联网时会使用系统字体。

## 页面内容

- 基础、高级、豪华、尊享四档会员套餐与权益。
- 五档积分包及自定义充值滑块、数字输入。
- 会员订阅支付弹窗，展示套餐积分、金额及自动续费信息。
- 积分单次购买弹窗，展示原积分、加赠积分、实付金额和有效期。
- 二维码演示、倒计时、刷新、弹窗关闭及键盘交互。
- 模型说明气泡和常见问题。

支付区域为前端演示，二维码不能用于付款。页面未接入实际支付、订单或自动续费接口；会员协议暂为名称展示，正文与链接待补充。

`index.html` 包含全部页面结构、样式与交互代码。
